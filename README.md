Welcome to my GitHub repository.

**Semester 2 – Object-Oriented Programming (C++)**
**College Admission & Record Management System**

A console-based application developed in C++ using Object-Oriented Programming principles. The system simulates a college admission process with proper data management and structured program design.

Key Features:
1. Student admission and registration management
2. Degree program handling
3. Merit list generation
4. File handling for persistent storage
5. Implementation of OOP concepts such as encapsulation and modular design

**Flight Management System (Final Term Project)**

A system designed using BST and AVL trees to manage flight records efficiently.

5. Handling delayed flight cancellations
